# 🎙️ خلاصه‌ساز هوشمند گفتار

یک ابزار تحت وب برای تبدیل فایل‌های صوتی به متن و خلاصه‌سازی هوشمند با استفاده از DeepSeek AI.

## ✨ ویژگی‌ها

- تبدیل صوت به متن با کیفیت بالا
- خلاصه‌سازی هوشمند با قابلیت‌های مختلف
- پشتیبانی از زبان فارسی و سایر زبان‌ها
- خروجی‌های متنوع (متن، JSON)
- رابط کاربری ساده و فارسی
